Restaurant Management System

You can register and login as a staff of different role (Cashier, Waiter, Kitchen staff and Owner) and different staff get different features based on their role.

________________________________________________________________________________________________________________________________________________________________________________________________

Cashier:

  ●Is responsible for checking in customers into available table
  
  ●They have access to payment detail for a specific table
  
  ●They can store payment detail
  
  ●They can check out customers
________________________________________________________________________________________________________________________________________________________________________________________________

Waiter:

  ●They can create orders for customer with their assigned table
  
  ●When order is submitted they are stored

________________________________________________________________________________________________________________________________________________________________________________________________

Kitchen:

  ●They are able to view orders that are not served
  
  ●They can Update order status to either preparing, ready or served
  
  ●They can mark each item for the order as complete

________________________________________________________________________________________________________________________________________________________________________________________________

Owner:

  ●They can view the total income and all order details for a chosen date

________________________________________________________________________________________________________________________________________________________________________________________________

How to make it work properly
  1. Cashier logs in to check in customers into an available table
  2. Waiter logs in and adds the order for checked in tables // note: waiter can only select tables that are occupied other wise it wont add in to payment details
  3. Kitchen logs in to view order and then complete the order
  4. Owner logs in at the end to check for profits and orders that have been paid (You cannot register as owner, here are prebuilt in date for owner, username: Owner, password: Owner1234)
